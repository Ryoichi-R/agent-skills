# Security Policy

## Supported versions

Only the latest published release is supported. Unpublished candidates and older releases may change without notice.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories: https://github.com/Ryoichi-R/agent-skills/security/advisories/new

Do not open a public issue for a vulnerability. GitHub issues are publicly visible, so never place secrets, exploit details, or personal information there. In the private advisory, include the affected skill or plugin, impact, reproduction steps, and any known mitigation.

Test only systems and data that you are authorized to use.
