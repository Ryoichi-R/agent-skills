# 詳細調査の戦略ガイド

## 汎用戦略（全ドメイン共通）

### トピック選定の優先順位

1. 「要検証」「未確認」「推論」と注記された主張
2. 出典が1つしかない主張
3. 結論に直接影響する主張
4. 抽象的な記述で具体例がない箇所

### 調査の深さの目安

- 1トピックあたり最低2つの独立した具体的事例を目標
- 各事例には出典（URL、ファイルパス、文献名等）を必ず付与

### 汎用検索パターン

- `"<キーワード> 事例"`
- `"<キーワード> 具体例"`
- `"<キーワード> case study"`
- `"<キーワード> 統計"`
- `"<キーワード> データ"`

## ドメイン別戦略

### 法令・制度・行政ドメイン

**キーワード**: 法, 条, 規則, 通知, 通達, 省庁, 調達, 入札, 契約

**検索パターン**:

- `"<キーワード> 判例"`
- `"<キーワード> 行政処分"`
- `"<キーワード> 通知"`
- `"<キーワード> Q&A"`

**優先情報源**:

- 省庁公式ページ
- 裁判所判例データベース
- 行政処分事例集
- 監査報告書
- パブリックコメント回答

**精査着眼点**:

- 条文解釈の実務運用
- 違反事例
- 行政指導の実績
- 自治体ごとの運用差異

### 技術ドメイン

**キーワード**: API, 実装, ライブラリ, フレームワーク, デプロイ, アーキテクチャ

**検索パターン**:

- `"<キーワード> implementation"`
- `"<キーワード> example"`
- `"<キーワード> benchmark"`
- `"<キーワード> 実装例"`

**優先情報源**:

- 公式ドキュメント
- GitHub リポジトリ
- 技術ブログ（著名エンジニア）
- Stack Overflow
- RFC/仕様書

**精査着眼点**:

- パフォーマンスベンチマーク
- 実装パターン比較
- 既知の問題・制約
- マイグレーション事例

### ビジネス・経営ドメイン

**キーワード**: 売上, 利益, 市場, ROI, 導入, コスト, KPI

**検索パターン**:

- `"<キーワード> 導入事例"`
- `"<キーワード> ROI"`
- `"<キーワード> 市場規模"`
- `"<キーワード> 成功事例"`

**優先情報源**:

- 業界レポート
- 政府統計（e-Stat）
- 白書
- IR資料
- プレスリリース

**精査着眼点**:

- 費用対効果
- 市場データ・統計
- 競合比較
- 導入企業の成果数値

## ドメイン自動判定ルール

入力ファイルの内容から以下のキーワードでドメインを自動判定する。

### 判定ルール

1. 各ドメインのキーワード出現回数をカウントする
2. キーワード出現回数が **3回以上** のドメインを該当ドメインとする（閾値: 3回）
3. 複数ドメインが閾値を超えた場合は、出現回数の多い順に優先し、該当する全ドメインの戦略を適用する
4. どのドメインも閾値に達しない場合は汎用戦略のみを適用する
5. 「法」等の1文字キーワードは文脈依存のため、`## ` で始まるヘッダー行内の出現は2倍にカウントする（見出しでの言及はドメイン特定性が高いため）
