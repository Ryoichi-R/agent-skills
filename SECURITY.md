# Security Policy

## Supported versions

Only the latest published release is supported. Unpublished candidates and older releases may change without notice.

## Reporting a vulnerability

Report vulnerabilities privately at https://github.com/Ryoichi-R/agent-skills/issues.
Do not place secrets, exploit details, or personal information in public issues. Include the affected skill or plugin, impact, reproduction steps, and any known mitigation.

Test only systems and data that you are authorized to use.
