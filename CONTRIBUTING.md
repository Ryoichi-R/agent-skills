# Contributing

Contributions that improve portability, documentation, tests, or safety are welcome.

## Before you start

Use https://github.com/Ryoichi-R/agent-skills/issues for general questions and proposed changes.
Keep changes focused. Do not submit credentials, private URLs, personal data, or machine-specific paths.

## Change requirements

- Preserve each skill's trigger conditions and safety boundaries.
- Keep plugin manifests and marketplace entries consistent with the packaged skills.
- Update documentation and add validation coverage for behavior changes.
- Run the validation steps documented by the affected skill before submitting a change.

Report security issues privately using the process in SECURITY.md.
